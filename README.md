# AyuVibe Frontend

AyuVibe is a user-friendly frontend application designed to bring the ancient wisdom of Ayurveda to modern users. The app provides a seamless platform for users to explore Ayurvedic remedies, connect with doctors, and learn about herbal treatments.  

This repository contains the source code for the frontend of the AyuVibe application, built to deliver an engaging and intuitive user experience.  

---

## Features

- **User Login**: Secure user authentication and personalized experience.
- **Doctor Directory**: Search and connect with certified Ayurvedic doctors.
- **Herbs and Remedies Database**: Access detailed information about Ayurvedic herbs and natural remedies.
- **Ayurveda Chatbot**: Get answers to your Ayurvedic questions instantly via an AI-powered chatbot.

## Getting Started

Follow these steps to set up and run the project locally:

### Prerequisites
- Node.js (v16 or later)
- npm or yarn installed
- Git installed

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Deshmukh1992/ayuvibe-frontend.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ayuvibe-frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
   or
   ```bash
   yarn install
   ```

### Running the Application

1. Start the development server:
   ```bash
   npm start
   ```
   or
   ```bash
   yarn start
   ```
2. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
